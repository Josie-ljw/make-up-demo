# 轻奢美妆小程序平台 · 产品规划与商业计划

## 一、一句话定位

我们想做的是：**面向中高端美妆服务场景的微信生态交易平台**——连接有审美的化妆老师 / 美妆工作室与有明确场景需求的 C 端用户，平台负责产品、流量与系统，供给侧专注内容与交付，平台按成交抽佣。

不是再做一家「卖课平台」或「泛美业 SaaS」，而是聚焦**高客单、强审美、强信任**的妆容服务与周边成交。

---

## 二、我们看到的机会

### 2.1 行业痛点

| 角色 | 现状问题 |
|------|----------|
| **用户** | 小红书 / 抖音能看到案例，但很难直接预约到「对的人」；价格不透明，信任成本高 |
| **化妆老师 / 工作室** | 有技术和作品，却缺稳定获客渠道；私域运营能力参差，转化链路断裂 |
| **品牌方** | 线下体验难规模化，线上又难找到匹配调性的场景化入口 |

### 2.2 为什么是现在

- **微信生态仍是国内最高频的消费入口**，小程序适合「浏览 → 咨询 → 预约 → 支付」的短链路
- **场景化妆需求在复苏**：婚礼、拍摄、活动、日常通勤妆等细分场景客单价清晰
- **内容平台导流成熟，但成交平台缺位**——用户被种草后，缺少一个「有审美、能下单」的承接页
- **AI 辅助开发降低早期产品成本**，使我们能在验证商业模式前先跑通视觉与结构 Demo

### 2.3 目标用户

**C 端（初期）**

- 25–40 岁女性，一二线城市为主
- 有婚礼、重要活动、拍摄、职场形象等明确场景需求
- 愿意为「审美 + 省心 + 专业背书」支付溢价

**B 端（供给侧）**

- 独立化妆老师、小型美妆工作室
- 有作品集、有口碑，但缺乏标准化线上成交工具
- 愿意以佣金换取稳定流量与品牌包装

## 三、产品与解决方案

### 3.1 产品形态

微信小程序（当前已有 H5 Demo 验证视觉与信息架构），核心模块：

```
首页（建立信任）→ 案例（看结果）→ 老师（选专业）→ 预约（成交）→ 我的（复购）
```

平台不是「内容社区」，而是**交易入口 + 信任中介 + 履约协调**。

### 3.2 平台价值

| 维度 | 平台提供什么 | 供给侧提供什么 |
|------|-------------|---------------|
| 产品 | 小程序、页面、预约、支付、订单 | 案例、课程、服务、商品 |
| 运营 | 流量投放、活动、转化优化 | 专业交付、售后 |
| 品牌 | 统一轻奢视觉、品质背书 | 个人 IP、作品集 |
| 收入 | 订单抽佣 + 增值服务费 | 服务 / 课程 / 商品收入 |

### 3.3 当前进展

- ✅ 完成轻奢风 Demo 页面（首页 / 案例 / 老师 / 预约 / 我的）
- ✅ 验证「不像电商、像美妆工作室」的视觉方向
- ⬜ 待做：支付、订单、分佣、商家后台、真实供给接入

> Demo 地址：`/beauty` 路由可预览产品气质，便于投资人直观感受定位。

## 四、商业模式

### 4.1 收入来源

| 来源 | 说明 | 预期占比（成熟期） |
|------|------|-------------------|
| **交易佣金** | 预约服务、课程、套装商品按 GMV 抽成（建议 8%–15%） | 主收入 |
| **增值服务费** | 老师主页装修、置顶推荐、活动坑位 | 辅收入 |
| **品牌合作** | 美妆品牌场景化联名、产品分销 | 长期收入 |

### 4.2 单位经济模型（逻辑框架）

以一笔 **￥899 晚宴妆预约** 为例：

```
用户支付 ￥899
  ├─ 平台佣金（10%）      ￥89.9
  ├─ 支付 / 渠道成本（约 1%）￥9
  └─ 供给侧结算            ￥800.1
```

平台早期不追求规模利润，先验证：**获客成本 < 单笔佣金 × 复购系数**。

### 4.3 与纯 SaaS / 纯内容平台的差异

- 比 SaaS 多一层**交易闭环**，天花板更高
- 比内容平台多一层**履约与信任**，客单价更高、用户更精准
- 比传统 O2O 更轻：供给侧以小微工作室为主，平台不自营重资产

## 五、市场与竞争

### 5.1 市场空间（定性判断）

中国美妆个人护理市场体量巨大，但**「场景化妆服务线上化」仍高度分散**：

- 大量交易发生在微信私聊、大众点评、小红书引流后线下成交
- 缺少专注「轻奢 / 中高端 / 审美导向」的垂直平台
- 婚礼、活动、拍摄等场景天然高客单，适合平台抽佣模型

> 我们不追求覆盖整个美业，而是先吃掉**「有审美要求的场景化妆服务」**这一细分切片。

### 5.2 竞争格局

| 类型 | 代表 | 优势 | 我们的差异化 |
|------|------|------|-------------|
| 综合 O2O | 大众点评、美团 | 流量大 | 缺乏美妆审美表达，偏比价 |
| 内容社区 | 小红书、抖音 | 种草强 | 成交链路长，信任难沉淀 |
| 美业 SaaS | 各类预约系统 | 工具成熟 | 不管流量，不管品牌 |
| 自营美妆品牌 | 完美日记等 | 供应链强 | 不做服务撮合 |

**我们的位置**：内容平台之后、线下门店之前的**「审美型成交层」**。

## 六、落地路径

### 6.1 三阶段规划

```
Phase 1 · 验证期（0–6 个月）
  目标：1–3 家种子工作室、100 单真实预约、跑通支付与分佣
  重点：供给侧 BD、小程序 MVP、转化数据

Phase 2 · 复制期（6–18 个月）
  目标：10–30 家工作室、覆盖 2–3 个城市、月 GMV 稳定
  重点：标准化入驻、本地投放、复购运营

Phase 3 · 平台期（18 个月+）
  目标：多城市、多品类（妆造 + 课程 + 选品）
  重点：品牌联名、数据驱动推荐、供给侧分层
```

### 6.2 关键里程碑

| 时间 | 里程碑 | 验证指标 |
|------|--------|----------|
| M1–M2 | MVP 上线（支付 + 预约 + 订单） | 可完成真实下单 |
| M3–M4 | 种子工作室 3 家 | 月预约 ≥ 30 单 |
| M5–M6 | 首轮投放测试 | CAC < 佣金收入 |
| M7–M12 | 城市复制 | 月 GMV 环比 20%+ |

### 6.3 冷启动策略

1. **供给侧先行**：先签 2–3 家有作品、有口碑的工作室，保证「打开就有好内容」
2. **场景切入**：从婚礼季 / 拍摄季等强需求窗口切入，不做泛流量
3. **视觉即信任**：用 Demo 已验证的轻奢视觉，区别于廉价预约工具
4. **私域 + 公域组合**：小红书种草 → 小程序成交 → 微信复购

## 七、核心优势

1. **审美壁垒**：产品气质本身即是筛选器，吸引高客单用户与优质供给侧
2. **轻资产模型**：不自营门店、不囤货，平台边际成本随规模下降
3. **微信生态红利**：支付、分享、复购链路天然顺畅
4. **AI 降本增效**：产品迭代与运营素材生产成本显著低于传统团队

## 八、风险与挑战

> 以下是我们认为投资人应重点关注的真实风险，而非回避项。

### 8.1 市场风险

| 风险 | 描述 | 应对思路 |
|------|------|----------|
| **需求频次低** | 婚礼 / 晚宴妆非高频消费，复购有限 | 拓展日常通勤妆、课程、补妆等中频场景；提高 LTV |
| **季节波动** | 婚礼、活动存在明显旺季 | 淡季推课程、套装、拍摄妆；供给侧弹性定价 |
| **消费降级** | 宏观环境下中高端服务承压 | 保留入门体验课（￥199 档）作为漏斗入口 |

### 8.2 运营风险

| 风险 | 描述 | 应对思路 |
|------|------|----------|
| **供给侧质量不稳定** | 化妆效果主观性强，易引发差评 | 入驻审核 + 作品集门槛 + 试妆机制 + 评价闭环 |
| **获客成本高** | 美妆投放竞争激烈 | 先做私域与内容引流，再小预算测试投放 ROI |
| **冷启动难** | 没有供给就没有用户，没有用户就招不到供给 | 种子工作室签约 + 平台补贴首单 + 线下活动导流 |

### 8.3 平台与合规风险

| 风险 | 描述 | 应对思路 |
|------|------|----------|
| **分佣与税务** | 个人老师接单涉及劳务 / 税务合规 | 早期引入灵活用工或第三方结算方案 |
| **微信政策变化** | 小程序规则、支付、类目审核可能调整 | 保持 H5 / 多端备用方案；合规先行 |
| **数据与隐私** | 用户照片、预约信息敏感 | 最小化采集、明确授权、安全存储 |

### 8.4 竞争风险

| 风险 | 描述 | 应对思路 |
|------|------|----------|
| **大平台下沉** | 美团 / 小红书若加强美妆垂直 | 聚焦审美细分，做平台不愿做的「重运营 + 重视觉」 |
| **供给侧跳单** | 用户与老师私下交易，绕过平台 | 会员权益、保障服务、分期支付等留在平台内的理由 |
| **同质化** | 美业 SaaS 工具泛滥 | 差异化在流量与品牌，不在工具本身 |

### 8.5 产品与技术风险

| 风险 | 描述 | 应对思路 |
|------|------|----------|
| **Demo ≠ 产品** | 当前仅有视觉验证，无真实交易 | 明确下一阶段 MVP 范围与时间表 |
| **多商户复杂度** | 订单、分佣、结算、售后系统工作量大 | 先单商户跑通，再抽象多商户架构 |
| **技术团队规模** | 早期人力有限 | AI 辅助开发 + 外包关键模块 + 分阶段上线 |

## 九、前景与愿景

### 9.1 短期（1 年内）

- 成为 **1–2 个城市的「场景化妆服务首选小程序」**
- 验证「审美型成交」模型成立：用户愿意为视觉信任付费
- 跑通 **GMV → 佣金 → 再投放** 的正向循环

### 9.2 中期（1–3 年）

- 扩展至 **妆造服务 + 课程 + 精选商品** 的复合平台
- 形成 **供给侧分层**：入门老师 / 资深老师 / 明星妆造师
- 探索 **品牌联名**：美妆品牌场景化营销与分销

### 9.3 长期愿景

> 成为「中国场景化妆服务的审美型交易平台」——  
> 用户想到婚礼妆、拍摄妆、重要场合妆，第一个打开的就是我们。

潜在延展方向：

- **To B**：为美妆品牌提供场景化体验与转化页
- **To Creator**：为化妆老师提供个人品牌官网 + 成交工具
- **数据资产**：场景偏好、价格带、地域需求等洞察（脱敏后）

### 9.4 为什么这件事值得做

1. **市场够大，但线上化够浅** — 大量交易仍在线下和私域
2. **客单价够高** — 单均数百至数千，佣金模型清晰
3. **审美是护城河** — 大平台不愿精耕，小工作室做不来
4. **微信生态窗口仍在** — 小程序仍是最高效的交易载体之一
