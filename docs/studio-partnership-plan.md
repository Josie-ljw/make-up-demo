## 一、先说清楚：我们帮什么、不帮什么

### 你们最擅长的事

- 化妆技术、审美判断、现场交付
- 案例拍摄、风格表达、客户沟通
- 婚礼妆、活动妆、拍摄妆、日常妆等**真实服务**

### 我们来做的事

- 帮你们把专业内容，放进一个**好看、能预约、能成交**的小程序里
- 帮你们承接从小红书、抖音、朋友推荐来的流量
- 帮你们处理预约、下单、订单记录等**线上琐事**

### 一句话

> **你们专注妆造，我们负责「让人看见你、信任你、找到你下单」。**

## 二、你们现在可能遇到的痛点

以下是我们和化妆老师、工作室聊下来，最常听到的真实困扰：

### 2.1 有作品，但难成交

| 现状 | 你们的感受 |
|------|-----------|
| 小红书 / 抖音有流量，评论里全是「怎么约？」 | 反复回私信，效率低 |
| 朋友圈发案例，点赞多、下单少 | 看了喜欢，但不知道价格、不敢问 |
| 客户要翻很多聊天记录才搞清楚服务 | 第一印象不够「专业、正规」 |

**本质问题**：内容有了，**成交页**没有。

---

### 2.2 私域运营太累

| 现状 | 你们的感受 |
|------|-----------|
| 预约靠微信接龙、Excel、备忘录 | 容易漏单、撞档 |
| 价格、档期、服务说明每次都要重讲 | 同样的话每天说很多遍 |
| 老客户复购靠记忆，没有系统提醒 | 明明服务过，却接不住第二次需求 |

**本质问题**：**工具分散**，人盯人，规模上不去。

---

### 2.3 线上形象不够「像你们」

| 现状 | 你们的感受 |
|------|-----------|
| 大众点评像比价平台，很难体现审美 | 和低价店混在一起 |
| 通用预约小程序像工具，没有工作室气质 | 客户觉得「不够高级」 |
| 自己搭页面，要么太土，要么太费时间 | 技术不是你们的强项 |

**本质问题**：线上页面**配不上**线下交付品质。

---

### 2.4 客单价高，但信任成本高

| 现状 | 你们的感受 |
|------|-----------|
| 婚礼妆、晚宴妆动辄几百到上千 | 客户决策慢、问得多 |
| 妆效主观，客户怕「踩雷」 | 需要大量案例和背书 |
| 新客不敢直接付定金 | 流失在「再看看」阶段 |

**本质问题**：缺少一个**持续建立信任**的线上空间。

---

### 2.5 淡季空档、旺季忙不过来

| 现状 | 你们的感受 |
|------|-----------|
| 婚礼季爆满，日常档期很空 | 收入波动大 |
| 只能卖「单次妆造」，课程、体验课卖不动 | 客单价和复购都有限 |
| 想推新手体验课，但没有合适入口 | 低价引流产品没地方放 |

**本质问题**：**产品结构单一**，缺少线上货架。

## 三、小程序能帮你们解决什么

我们把上面的痛点，对应到小程序的具体能力：

```
                    ┌─────────────────────────┐
  小红书 / 抖音 /     │                         │
  朋友推荐 ────────▶ │   轻奢美妆小程序         │ ────▶ 预约 · 下单 · 复购
                    │                         │
  你们的案例 / 老师  │   首页 / 案例 / 老师     │
  课程 / 服务       │   预约 / 我的            │
                    └─────────────────────────┘
```

### 3.1 痛点 → 解决方案对照

| 你们的痛点 | 小程序怎么帮 |
|-----------|-------------|
| 有作品难成交 | **案例页**集中展示妆效，价格一目了然，一键预约 |
| 私域运营太累 | **预约页**标准化服务说明、档期、价格，减少重复沟通 |
| 线上形象不够高级 | **轻奢视觉**整体包装，像工作室官网，不是廉价工具 |
| 信任成本高 | **老师页 + 案例页**持续沉淀专业背书，新客敢下单 |
| 产品结构单一 | 同时承接**单次服务、体验课、后续课程**等多种 SKU |
| 流量接不住 | 主页、主推位、场景分类，帮客户**快速找到对应需求** |

## 四、五个页面，分别帮你们做什么

> 当前已有 Demo 可预览，以下为上线后对工作室的实际价值。

### 4.1 首页 —— 你的「线上门面」

**帮你们：**

- 第一眼建立「专业、轻奢、靠谱」的印象
- 展示今日主推（体验课、当季活动、爆款服务）
- 用场景分类（婚礼 / 通勤 / 约会 / 拍摄…）帮客户对号入座

**你们只需提供：**

- 工作室名称、主推服务、代表案例图
- 想重点推的价格带和活动

**客户感受：**

> 「这不是随便的个人接单，是一家有审美的工作室。」

---

### 4.2 案例页 —— 你的「作品集」

**帮你们：**

- 把散落的客片、妆前妆后，整理成**可浏览、可转发**的案例库
- 每个案例带场景标签和价格参考，减少「这个多少钱？」的反复询问
- 海报区强化审美表达，适合转发到朋友圈、小红书

**你们只需提供：**

- 高清案例图（建议统一色调）
- 简短妆效说明、适用场景

**客户感受：**

> 「这个效果就是我想要的，而且价格我能接受。」

---

### 4.3 老师页 —— 你的「专业名片」

**帮你们：**

- 每位老师独立展示：风格、经验、擅长场景、代表标签
- 强化个人 IP，适合客户**指定老师预约**
- 数据亮点（服务案例数、评分、响应速度）增加信任感

**你们只需提供：**

- 老师简介、头像、擅长风格、标签

**客户感受：**

> 「这位老师擅长婚礼妆，我想约她。」

---

### 4.4 预约页 —— 你的「成交台」

**帮你们：**

- 服务项目、价格、说明**标准化展示**，不用每次微信重发
- 客户可在线选服务、留信息、付定金（上线后）
- 减少漏单、口头报价不一致等问题

**你们只需提供：**

- 服务项目清单、价格、服务包含内容
- 可预约时段规则

**客户感受：**

> 「流程清楚，我可以直接约，不用聊十句才到正题。」

---

### 4.5 我的页 —— 你的「客户留存区」

**帮你们：**

- 客户可查看订单、收藏案例、关注老师
- 为**复购、补妆、进阶课程**留入口
- 长期把一次性客户变成可回访用户

**你们只需提供：**

- 后续可推的复购服务（补妆、课程、套装等）

**客户感受：**

> 「上次约的老师和案例都在这里，下次还能找到。」

| 事项 | 美妆工作室 | 我们（平台方） |
|------|-----------|---------------|
| 化妆服务交付 | ✅ | — |
| 案例、客片、老师资料 | ✅ | 协助整理上架 |
| 定价与服务说明 | ✅ | 协助优化展示 |
| 小程序页面与视觉 | — | ✅ |
| 预约 / 下单 / 订单系统 | — | ✅ |

**你们不需要：**

- 自己写代码、搭网站
- 研究复杂的后台系统
- 单独做一套预约工具

**你们需要：**

- 提供真实、高质量的内容（案例、老师、服务）
- 保证交付品质（这是口碑的核心）
- 配合上线初期的活动与反馈

## 六、对工作室的实际好处

### 6.1 省时

- 价格、服务说明、案例**一次上架，反复使用**
- 减少 70% 以上的重复私信沟通（预估，视工作室规模而定）

### 6.2 涨单

- 流量进来后有**明确成交路径**，不是「看了就划走」
- 体验课、婚礼妆、活动妆**分场景承接**，提高转化

### 6.3 提价

- 轻奢视觉包装支撑**中高端定位**
- 不再和大排档式低价店挤在同一个比价页面里

### 6.4 做品牌

- 小程序是你们的**长期线上资产**
- 案例、老师、口碑持续积累，越用越值钱

### 6.5 扩品类

- 不只卖「一次妆造」，还能卖**课程、体验课、后续服务**
- 淡季有产品可推，不只等婚礼季

## 七、合作模式（透明说明）

### 7.1 怎么赚钱

- 客户通过小程序下单，**工作室拿服务收入**
- 平台按成交额收取**佣金**（具体比例签约前明确，公开透明）
- 早期种子合作工作室，可享**更低佣金或流量扶持**

### 7.2 你们关心的问题

**Q：客户加了微信，私下交易怎么办？**

平台提供的是**信任、流量、工具、保障**。我们会通过会员权益、订单保障、分期支付等方式，让客户愿意留在平台内完成交易。但根本上，**服务质量**才是客户回来的理由。

**Q：案例照片版权归谁？**

默认归工作室所有。平台仅在小程序内展示推广，不会擅自用于其他用途。具体以合作协议为准。

**Q：价格谁定？**

**你们定价。** 平台可给建议（比如体验课引流价、婚礼妆套餐价），但不强制。

**Q：已有老客户怎么办？**

老客户可以继续微信服务。小程序主要帮你们**接新客、做标准化、沉淀案例**，不是替代现有私域。

**Q：技术门槛高吗？**

不高。你们负责提供内容和确认信息，**页面、系统、维护由我们完成**。

## 八、适合什么样的工作室

我们更适合与以下类型的伙伴合作：

| 适合 ✅ | 可能不适合 ❌ |
|--------|-------------|
| 有清晰风格与代表作品 | 无任何案例展示 |
| 愿意维护线上形象 | 只接极低价、不 care 品牌 |
| 服务婚礼、活动、拍摄、日常妆等场景 | 只做产品代购、不做服务 |
| 希望稳定获客、减少重复沟通 | 仅想免费蹭流量、零配合 |
| 客单价在 ¥199 以上 | 纯比价、无差异化 |

## 九、上线后，你们的一天会变成什么样

**以前：**

```
发小红书 → 私信问价 → 反复解释 → 手动记档期 → 微信收款 → 完成服务
```

**合作后：**

```
发小红书 / 朋友圈 → 客户点进小程序 → 看案例、选老师、直接预约
    → 系统通知你们 → 确认档期 → 线下交付 → 客户复购有记录
```

你们从「客服 + 销售 + 运营」里解放出来，**更多时间放在妆造本身**。
